# WaterPhysics – Описание для Modrinth

Реалистичная физика воды на Paper/Spigot. Вода ведёт себя как конечный ресурс: сколько налил, столько и вытек. Никаких дюпов.

---

## Важно перед установкой

⚠️ Вы можете использовать этот плагин на серверах по выживанию, но должны быть готовы к потреблению ресурсов либо жёстким ограничениям (редактировать через config.yml). Изначально я делал этот плагин для сессионных мини-игр.

---

## Длинное описание

### Вода, которая ведёт себя как настоящая

WaterPhysics переписывает поведение воды на модели конечного ресурса. Каждый блок воды содержит целое число "единиц" (1–8):
- **8 единиц** = источник (полный блок)
- **1–7 единиц** = текущая вода
- **0 единиц** = воздух

Никогда не создаёт и не уничтожает единицы. Всё, что вы залили, ровно столько и вытечет.

### Как это работает

🌊 **Гравитация** – вода мгновенно падает вниз на один тик, заполняя колонну снизу вверх. Нет медленного капания.

🧊 **Адъюстация уровней** – вода выравнивается с соседями на одном уровне. Когда есть выход вниз, стекает полностью.

🔍 **Поиск слива** – вода на плато ищет ближайшую яму в радиусе до 1024 блоков и ползёт туда, заполняя всё озеро.

💧 **Падающие фильмы** – боковой сток через край сразу падает вниз как водопад, не зависая в воздухе.

🌀 **Испарение луж** – тонкие одиночные слои воды, которые больше никуда не текут, исчезают (отключаемо).

### Поддержанные события

💥 **Взрывы** – TNT, криперы, кровати и якоря открывают дыры, вода течёт в кратер.

🔧 **Поршни** – поршни сдвигают блоки, вода пробирается в освободившиеся пространства.

🪣 **Вёдра** – размещение ведра переквеуирует воду вокруг, позволяя ей разливаться заново.

🌡️ **Лава (опционально)** – если включить `lava.apply-physics: true`, лава течёт по той же системе (экспериментально). По умолчанию лава остаётся ванильной.

💧 **Водозаполнение** – лестницы, плиты, заборы автоматически водозаполняются при подходящем уровне рядом.

🔊 **Звуки + частицы** – опциональные эффекты при потоке воды (частицы видны только рядом с игроком).

### Оптимизация для выживания

⚡ **Main thread только** – никакого async, полностью безопасно для Paper.

🎯 **Проверка близости игроков** – вода обрабатывается только в загруженных чанках рядом с игроками. Далёкие океаны не трогаются.

💾 **Кэш с TTL** – блоки забываются из памяти через 60 секунд если не используются.

🚫 **Исключение биомов** – отключить физику в океанах/реках через список биомов.

🧩 **Режим "Только взаимодействие"** – вода течёт только когда игрок ломает/ставит блок рядом. Статичная вода не трогается.

📊 **bStats** – телеметрия включена, показывает ваши настройки (опционально через /opt-out).


### Для кого это

🏗️ **Выживание** – реалистичная гидравлика, красивые водопады, честная система

🎮 **Мини-игры** – настраиваемые затопления, водные ловушки, гонки на лодках

🎨 **Творчество** – механики водных ловушек, паркур с водопадами, генераторы ресурсов

### Требования

- Paper 1.21.3+
- Java 21+ (Java 25 поддерживается)
- Gradle 8.0+ (только для сборки)

Никаких зависимостей. Работает автономно.

### Настройка (config.yml)

```yaml
enabled: true
worlds: ["*"]                    # Все миры или список

flow:
  interaction-only: true         # Вода течёт только на break/place
  batch-size: 512                # Блоков в тик (больше = быстрее, но лагит)
  tick-interval: 3               # Каждые N тиков запускать

optimization:
  player-proximity-check: true   # Только рядом с игроками
  player-proximity-chunks: 4     # Радиус в чанках
  cache-ttl-seconds: 60
  cache-max-size: 100000

effects:
  enabled: true                  # Частицы при потоке
  rate-limit-ticks: 4

lava:
  apply-physics: false           # Экспериментальная физика лавы
```

Всё раскрыто и настраивается на лету через `/wp reload`.

### FAQ

**Р: Будет ли лаг?**
О: Зависит от конфига. По умолчанию включен режим "только взаимодействие" и проверка близости игроков — на небольших серверах отлично работает. На больших обязательно настроить `batch-size` и `tick-interval`.

**Р: Вода зависает, не течёт?**
О: Вероятно, озеро/река в исключённом биоме (по умолчанию `ocean`, `river` и т.д.). Удалите из списка `excluded-biomes` в config.yml.

**Р: Может ли это работать с ванильным поршнем?**
О: Да. Поршень толкает блок → вода пробивается в щель. Работает для TNT, криперов и поршней одновременно.

**Р: Сколько памяти нужно?**
О: На выживание ~100k кэшируемых блоков = 3–4 МБ. Зависит от `cache-max-size` в config.
